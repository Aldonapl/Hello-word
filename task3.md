Task 3 - Describe the difference between fetch and pull and show (briefly) how each would be used. 
The git fetch command is used to download changes from a remote repository to your local repository without modifying your working directory. 
It updates your remote-tracking branches, allowing you to see what others have committed without affecting your current work
The git pull command is a combination of git fetch followed by git merge. 
It retrieves changes from the remote repository and immediately integrates them into your current branch, updatinand modifies your working files right away.
